# 실행 예시

같은 요청으로 두 모드를 실행한 결과가 프로젝트 `examples/` 폴더에 있다. 형식이 헷갈릴 때만 열어 본다.

| 파일 | 내용 |
|---|---|
| `examples/01_요청문.md` | 두 실행의 출발점이 된 요청문 |
| `examples/02_스킬미적용_초안.md` | 스킬 없이 생성한 초안. 점검 모드의 입력 |
| `examples/03_실행결과_점검모드.md` | 02를 점검 모드로 판정한 결과 (위반 3·보완 3·충족 2) |
| `examples/04_실행결과_작성모드.md` | 01을 작성 모드로 실행한 결과 |
| `examples/05_ClaudeCode_점검모드_실행결과.md` | 02를 Claude Code에서 점검 모드로 실행한 결과 (위반 3·보완 2·충족 3) |

## 점검 모드 출력의 핵심 형태

```
## 표 2. 규칙 판정
| 규칙 | 판정 | 근거(초안 문구 인용) |
|---|---|---|
| 1. 가설 수 = 모형 화살표 수 | 위반 | 모형의 화살표는 4개인데 가설은 H1~H6 6개다. … |
...
**집계**: 충족 2(규칙 5·6) / 보완 3(규칙 2·3·4) / 위반 3(규칙 1·7·8)
```

## 작성 모드 출력의 핵심 형태

```
> **작성 가정** (질문할 사람이 없을 때만)
## Ⅰ. 뼈대
### ① 연구제목
...
## 자체 점검표
| 규칙 | 결과 | 근거 |
```
