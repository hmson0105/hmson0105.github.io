양적연구 계획서 설계·점검 스킬

목적 계획서의 항목을 채우는 데서 그치지 않고, 앞에서 정한 것과 뒤에서 쓰는 것이 어긋나지 않게 한다.

0. 모드 선택과 파일 입출력 (Claude Code)

  • 사용자가 초안 파일 경로를 주면 점검 모드, 주제·변수·데이터 설명을 주면 작성 모드로 실행한다.
  • 점검 모드에서는 초안 파일을 Read로 끝까지 읽은 뒤 판정한다. 초안 파일은 수정하지 않는다.
  • 결과는 outputs/ 폴더에 마크다운으로 저장한다. 파일명은 점검 모드 check_<초안파일명>.md, 작성 모드 plan_<주제 키워드>.md. 저장 후 경로와 규칙 판정 집계(충족/보완/위반 개수)를 한 줄로 알린다.
  • 질문할 사람이 없는 실행(claude -p)이면 질문 대신 합리적 가정을 세우고 결과 맨 위에 "작성 가정" 2~3줄로 밝힌다.
  • 출력 예시는 examples.md를 참고한다.

1. 절차

단계작성 모드 (주제·변수·데이터 → 초안)점검 모드 (초안 → 판정)
① 입력 확인독립·종속·매개·조절변수, 데이터 수집 방식 확인. 빠진 정보는 질문초안을 아래 22개 요소에 하나씩 대응
② 작성·대조5단계 22개 요소를 순서대로 작성요소별 상태 판정(충족/보완/누락)
③ 정합성 판정규칙 8개로 자체 점검규칙 8개 판정(충족/보완/위반)
④ 출력초안 + 자체 점검표판정표 + 우선 수정 순서. 초안을 다시 쓰지 않음

22개 구성요소

  • 뼈대: ①제목 ②유형(횡단/종단 명시) ③연구모형 ④가설
  • 정당성: ⑤배경 ⑥이론(1개) ⑦선행연구(이 이론을 쓴 실증 3편) ⑧차별성(2가지)
  • 데이터: ⑨데이터 ⑩분석단위 ⑪측정수준 ⑫모집단 N ⑬표본 n(검정력 근거) ⑭표집방법(장점·한계)
  • 분석: ⑮종속변수 분포 ⑯변수 간 예상관계 ⑰분석방법 ⑱가상결과
  • 의미: ⑲이론적 함의(2) ⑳정책 함의(2) ㉑한계(3개 이상) ㉒결론(5개 항목 각 1문장)

2. 판단 기준

#정합성 규칙대조 요소
1가설 수 = 모형 화살표 수 (통제변수 경로 제외)③↔④
2제목의 변수 = 모형의 변수①↔③
3⑥에서 고른 이론이 이론적 함의에서 다시 다뤄짐⑥↔⑲
4차별성이 분석결과로 실제 드러날 수 있음⑧↔⑱
5데이터 단위 = 분석 단위 = 표본 단위⑨↔⑩↔⑬
6분석방법이 종속변수 측정수준에 맞음 (연속→OLS, 이분→로지스틱, 서열→순서형 로짓, 횟수→포아송·음이항)⑪⑮↔⑰
7정책 논조의 강도 = 결과의 강도. 측정하지 않은 변수로 권고하지 않음⑱↔⑳㉒
8횡단면 자료이면 "영향을 미친다" 같은 인과 표현을 쓰지 않음②↔①④⑱~㉒
  • 판정 등급: 위반 = 규칙이 깨져 결론이 흔들림 / 보완 = 표현·일부 누락 수준 / 충족
  • 작성 원칙: 가상 수치에는 "가상" 표시 · 확인되지 않은 문헌은 지어내지 않고 [저자, 연도]로 남김 · 결과가 유의할 때만 "~해야 한다" · 한계는 표본 크기처럼 노력으로 극복할 수 있는 것보다 역인과·동일방법편의·외적 타당성 같은 구조적 한계를 우선

3. 출력 양식

작성 모드 — ①~㉒ 번호 순 초안 → 마지막에 규칙 | 결과(충족/보완/위반) | 근거 표 8행
